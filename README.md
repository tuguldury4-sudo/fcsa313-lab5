## Дүгнэлт

Таван алхмаас нөхцөлүүдийг давхцах эсэхээр нь ангилах хамгийн их бодол шаардсан. Оюутан байхгүй үед түүний үзсэн хичээлийн төлөвийг бэлдэх боломжгүй. Идэвхгүй оюутан байхгүй хичээлд бүртгүүлэхэд оюутны төлөвийг эхэлж шалгасан. Зарим урьдач нөхцөлийг хангахад `missing` жагсаалтад зөвхөн дутсаныг шалгасан. Урьдач нөхцөлгүй хичээл хоосон түүхтэй оюутанд амжилттай бүртгэгдсэн. PUT setup нь тус бүрийн оролтыг бие даан бэлдсэн. Үндсэн 10 кейсэд тодорхойлолтоос зөрсөн хариу ажиглагдаагүй. Санаатай өөрчилсөн HTTP oracle ганц assertion унагаж, quality gate exit 1 буцаасан.
